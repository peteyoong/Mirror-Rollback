The user wants to build Project Mirror, a mobile-first reflective AI app. The session focused on implementing a sophisticated, LLM-powered chat companion named Mirror with multiple contexts and advanced backend features.

The initial request was to create a hybrid chat system:
1.  Keep the existing template-based Reflect with Mirror feature in the Journal.
2.  Add a new, primary Mirror chat experience in the Journal tab, powered by an LLM that synthesizes all user data.
3.  Add lens-specific Ask about this lens chat entry points within each Lens screen (Astrology, Human Design).

This evolved into a multi-step implementation process, including UI polishing, data persistence, and adding layers of intelligence and safety to the backend.

The final user request was to implement Prompt 11: a personalized, reflective greeting on the main Mirror home screen, designed to create a moment of quiet recognition by synthesizing the user's chart data without explicitly naming the systems (Astrology, Human Design, etc.).

PRODUCT REQUIREMENTS:
-   **Mirror Chat (LLM-Powered)**:
    -   A primary chat interface in the Journal tab, togglable with the journal entry view.
    -   Lens-specific chat interfaces accessible via modals from within each lens screen.
    -   The chat AI must follow a strict, non-prescriptive, reflective philosophy.
    -   Conversations must be persistent across app reloads.
-   **You Over Time Memory**:
    -   The backend must generate a structured summary of the user's recurring themes, tensions, and emotional state based on their chat and journal history.
    -   This summary should be displayed in the UI in a calm, collapsible card.
-   **Timeline Tracking**:
    -   The backend must log a lightweight, privacy-safe timeline event for each chat turn to track the user's journey over time.
    -   A new Timeline view in the Journal tab should display these events.
-   **Safety & Cost Control**:
    -   The backend must have guardrails to detect and rewrite non-compliant AI responses (e.g., advice, predictions).
    -   Rate limiting and context-size limits must be in place.
-   **Emotional Keystone (Prompt 11)**:
    -   The main Mirror tab (home screen) should display a personalized, poetic, and reflective greeting that synthesizes the user's chart data without naming any systems.
