**Code Architecture**


**Key Technical Concepts**
- **Deterministic-First Architecture:** A new core pattern established in this session. Core UI surfaces load instantly using pre-defined templates or fast-computed data. This provides a fast, reliable user experience.
- **Background LLM Enrichment:** The companion pattern to the above. After the deterministic UI is rendered, a background task is triggered to generate richer, personalized content from an LLM. This result is then cached and used to silently update the UI or for subsequent loads.
- **Silent UI Updates:** The frontend Home screen now polls for an enriched version of its content and updates the view without a jarring flash or loading spinner, creating a seamless personalization effect.
- **Component-level State Management:** Debugging highlighted the importance of managing component state during tab switching, especially when different tabs rely on API responses with different data structures (e.g., HD Overview vs. Deep Dive).
