**Code Architecture**


**Key Technical Concepts**
- **Deterministic-First Architecture**: Core UI surfaces load instantly; complex analysis (like Pattern Drift) is done via separate, cached API calls.
- **Reflective, Non-Deterministic Copy**: A core product philosophy. UI text is written to be invitational and observational (You may notice...) rather than diagnostic (You are...).
- **Component-level State Management**: Using  to trigger data fetching when a screen becomes active.
- **Deterministic Signal Detection**: Using keyword clusters, source weighting, and rolling time windows to analyze text for patterns without relying on ML/LLM for the core detection.
- **Robustness Guardrails**: Implementing checks (e.g., minimum number of entries or distinct keywords) to prevent low-quality signals from generating a result.
