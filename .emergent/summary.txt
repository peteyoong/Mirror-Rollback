**Code Architecture**


**Key Technical Concepts**
- **Multi-Environment Architecture**: Managing separate STAGING and PROD deployments by using distinct Emergent applications, each with its own configuration and isolated database.
- **Environment-Specific Configuration**: Using  files and build-time variables (, ) to enable/disable features and configure behavior for different environments.
- **Defensive Backend Programming**: Wrapping API handlers in  blocks to prevent crashes (5xx errors) and return structured JSON error messages with specific details.
- **Robust Frontend Error Handling**: Parsing structured JSON errors from the backend to display user-friendly, actionable messages in the UI instead of generic failure notices.
- **Stateful Onboarding Flow**: Managing a multi-step process using component state (), persisting progress to avoid resets on refresh, and disabling navigation until the current step's data is valid.
- **Non-Blocking Debug UI**: Implementing debug panels as collapsible or modal elements, conditionally rendered only in non-production environments, to ensure they don't interfere with core application functionality.
- **Client-Side Session Management**: Using Zustand and AsyncStorage to manage user sessions, including login, logout, and a full local data reset for development purposes.
